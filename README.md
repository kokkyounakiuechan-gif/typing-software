# タイピングソフト

日本語のお題をローマ字で入力する、難易度4段階（ホームポジション／初級／中級／上級）のタイピング練習ゲームです。

お題が表示され、入力に合わせて手のイラストとキーボード配列が「次に打つキー・指」を光らせて教えてくれます。終了するとタイム・正解数・ミス数・速度・正確率を結果画面に表示します。

## リポジトリURL

https://github.com/kokkyounakiuechan-gif/typing-software
